# 🌐 Portfólio Pessoal - em produção

Este repositório contém meu portfólio desenvolvido com foco em apresentação profissional, projetos autorais e habilidades técnicas. Ele foi construído utilizando:

- **HTML5** – Estruturação semântica das páginas
- **CSS3** – Estilização moderna e responsiva
- **JavaScript** – Funcionalidades interativas e dinâmicas

## 🎨 Funcionalidades

- Design responsivo para diferentes tamanhos de tela
- Animações suaves e efeitos visuais com CSS
- Interatividade com JavaScript (botões, menus e mais)
- Seção de projetos com links para cada repositório

## 🚀 Como rodar localmente

1. Clone o repositório:  
   `git clone https://github.com/seu-usuario/seu-repositorio.git`
2. Abra o arquivo `index.html` em seu navegador
3. Pronto! Seu portfólio estará visível localmente
